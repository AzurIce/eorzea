# 补丁流水线与中断恢复

## 队列模型

`GameFileManager::update` 为 CLI 与 GUI 提供同一条更新流水线：

- 下载任务按列表顺序领取槽位，允许乱序完成；默认 4 路网络并发。
- 预取窗口限制为“当前补丁 + 并发数”，正在下载、校验及等待安装的任务都占窗口，不能无限积压缓存。
- 应用 routine 只取队头，下载和校验未完成就等待，不能跳过它应用后续补丁。
- 应用在阻塞线程池执行，进度通过共享快照在调用线程回调；GUI signal 不跨线程读写。
- 下载与应用分组独立显示整体与子任务进度；GUI 的任务和状态位于根组件，切换页面不会取消。

## 持久化清单

`<游戏根目录>/.eorzea/update.json` 保存有序补丁元数据（URL、大小、版本和校验信息）、绝对缓存目录及消费游标。不记录完整安装历史，也不记录补丁内部执行位置。

清单在第一次修改游戏文件前保存；每份补丁依次执行：

1. 下载完整并校验。恢复时同样重新校验，不能沿用上一进程的内存标记。
2. 从头流式应用，必须读到 `EOF_`。
3. 检查并同步游戏文件；Unix 上同步修改的目录。关闭写入句柄。
4. 用同目录临时文件、文件同步和原子替换提交对应仓库 `.ver`。
5. 删除补丁并同步缓存目录，持久化队头位置，才允许处理后继补丁。
6. 全部成功后更新 `.bck`，删除清单。

`update.lock` 使用操作系统文件锁，退出时由系统释放；锁文件本身不删除。应用 worker 持有锁的共享所有权，即使调用任务取消，仍在执行的同步 worker 也不会提前释放锁。

## 中断行为

- 下载中断：已有前缀按 SHA1 检查后 Range 续传，必要时重下。
- 应用中断或应用失败：清单队头不变，保留当前完整补丁，从补丁开头重放。
- `.ver` 已提交但补丁未删除：仍只重放当前补丁，后继尚未执行，不存在旧补丁覆盖新补丁的问题。
- 补丁已删除但游标未持久化：按旧队头重新下载并应用同一补丁；允许重复处理，不猜测已成功。
- 游标已推进：不再调度之前的补丁。
- 删除失败：停止推进；修复权限或占用后重试，不能继续安装后继。
- 下载最终失败时：停止调度和取消其他下载；已经开始的应用会完成或报错，之后返回失败，不遗留持有游戏写入句柄的后台应用。
- `.bck` 或最终清理失败：保留完成位置，重试只补做结束清理。

重启先读清单，再考虑请求服务端列表，不能依赖 `.ver` 推导未完成队列。清单损坏或与传入队列冲突时明确失败；不能静默替换原队列。未完成清单存在时不允许启动游戏。

## 为什么从头重放

当前支持的主要操作是固定位置写入固定内容，不读取旧游戏内容计算差分：

- `SQPK:A` 写入指定偏移，再清零固定长度；不是向文件末尾追加。
- `SQPK:D/E` 写入指定位置的空块与零数据。
- `SQPK:H` 覆盖固定位置的文件头。
- `SQPK:F/AddFile` 在偏移 0 时截断，再按指定偏移写补丁携带的解压数据。
- 删除与建目录可重复执行；每次重放使用新的 `ApplyContext`，不能跳过前置命令或乱序执行。

删除前关闭、移除缓存的文件句柄；目录删除也清理其子路径句柄，避免 Linux 上写入已 unlink 的 inode 或 Windows 上无法删除。真正的 I/O 错误返回失败，NotFound 可视为删除完成。

`RemoveAll` 会清理资料片目录里的 `.ver` 和 `.bck`，所以恢复清单放在根目录 `.eorzea/`，不放在资料片目录。清单游标是未完成队列的依据，不要求上一份 `.ver` 始终存在，也不需要整游戏备份。

## 验证与边界

仓库回归测试覆盖：

- 本地 HTTP 服务暂停后续下载，确认前一份已经安装；暂停队头，确认后续下载完成也不会先安装。
- 预取窗口、下载并发、最终文件内容、版本、缓存删除与两个进度的完成状态。
- 部分游戏文件和缺失 `.ver` 下离线恢复完整缓存。
- 结束标记缺失时禁止提交版本和应用后继。
- 删除后队头尚未持久化的重下载、删除权限失败重试、更新互斥和完成队列清理。
- 文件/目录删除后重建，以及 RemoveAll 后重新应用。

临时研究探针位于 `/tmp/opencode/patch-recovery-probe/`；合成序列的 16 个前缀中断点及一次部分写入，在从头重放后与干净应用的最终文件字节一致。该探针只用于研究，不是项目运行依赖。

这些验证不是完整发行补丁、真实强杀或断电验证。Windows 与文件系统/硬件的电源故障持久化保证仍需单独验证，不能承诺恢复补丁写入范围以外的磁盘损坏。无 SHA1 的 boot 补丁还缺下载阶段的逐 chunk CRC 校验；当前安装检查结构与结束标记。
